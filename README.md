# 🌐 Personal Resume Website

A responsive personal portfolio and resume website built using **HTML, CSS, and JavaScript**. This website showcases my profile, skills, projects, education, and contact information in a clean and user-friendly interface.

## 🚀 Features

- Responsive design for desktop and mobile
- Home page with introduction
- Resume page
- Contact page
- Clean and modern UI
- Easy to customize

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📂 Project Structure

```
resumewebsite/
│── index.html          # Home page
│── resume.html         # Resume page
│── contact.html        # Contact page
│── style.css           # Stylesheet
│── script.js           # JavaScript functionality
│── Dockerfile          # Docker configuration
│── README.md           # Project documentation
```

## ▶️ How to Run

### Method 1: Open Directly

Download or clone the repository and open `index.html` in your web browser.

### Method 2: Using VS Code

1. Open the project in VS Code.
2. Install the **Live Server** extension.
3. Right-click on `index.html`.
4. Select **Open with Live Server**.

### Method 3: Using Docker

Build the Docker image:

```bash
docker build -t resumewebsite .
```

Run the container:

```bash
docker run -d -p 8080:80 resumewebsite
```

Open:

```
http://localhost:8080
```
